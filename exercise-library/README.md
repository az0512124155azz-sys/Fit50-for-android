# ספריית תרגילי התלת־ממד של Fit50+

מנהל נפרד למחשב עם **66 תרגילי בסיס ו־24 גרסאות בקצב איטי**. הגרסאות
האיטיות משתמשות באותה תנועה בקצב 70%; הן אינן 24 תנועות חדשות.
הספרייה משתמשת בדמות התלת־ממד היחפה של האפליקציה. לכל פריט קובץ JSON
בתיקיית `exercises`, ובו השם, קבוצת השרירים, סוג התרגיל והתנועה המשויכת.

## פתיחה והוספה בלחיצה

1. פתח את התיקייה בעותק הפרויקט במחשב.
2. לחץ פעמיים על **Open Library.cmd**. נדרש Node.js 22 ומעלה; בהפעלה
   הראשונה יותקנו תלויות הבנייה של התצוגה.
3. חפש תרגיל וצפה בהדגמה. לחץ **הוסף לאפליקציה**.

הכפתור מעדכן את `active.json`, את קטלוג Kotlin ואת חבילת ההדגמות.
התרגיל החדש יורש את הגבלות ההתאמה, קבוצות המטרה, המינון והנחיות הבסיס.
הוא נעשה זמין למחולל האימונים; אין הבטחה שיופיע בכל אימון שנוצר.
תרגילי הבסיס נשארים פעילים. תוספת ניתנת להסרה באותו כפתור.

השמירה היא בעותק הפרויקט במחשב. יש להעלות את השינויים ל־GitHub כחלק
מעדכון הפרויקט; הכלי אינו שומר סיסמאות GitHub ואינו דוחף קומיטים אוטומטית.
השינוי יופיע בטלפון בגרסה הבאה שתיבנה מהקוד. הכלי **אינו יוצר APK**.
לסגירה, סגור את חלון השרת שנפתח. GitHub עצמו מציג קבצים ואינו מפעיל
את מנהל הספרייה מתוך דף התיקייה.

## תנועות נוספות ושיפור הדגמות

הספרייה כוללת הדגמות תלת־ממד מתואמות לכל 66 תרגילי הבסיס. אלה תנועות
שנבנו בקוד ולא הוקלטו מאדם או נבדקו מקצועית. בדוק את התצוגה לפני שימוש.
השדה `animation` מציין שהתנועה משתמשת במערכת הגוף המתואמת.

כדי להכין עוד גרסת קצב, הוסף קובץ JSON עם מזהה ושם ייחודיים,
`kind: "tempo-variant"` והפניה לתנועת בסיס קיימת ב־`motion.id`.
מנהל הספרייה יזהה אותו בהפעלה הבאה. מהירות נתמכת: 0.4–1.5.
תנועה חדשה באמת דורשת קודם אנימציה חדשה ב־`tools/coach` ותרגיל בסיס
בקטלוג Android; שינוי השם של תנועה קיימת אינו יוצר הדגמה חדשה.

## פיתוח ובדיקות

מהתיקייה הראשית של הפרויקט:

```sh
node exercise-library/tools/server.mjs
node exercise-library/tools/test.mjs
node tools/coach/test.mjs
node tools/coach/test-motion.mjs
```

השרת מאזין רק ב־127.0.0.1. כתיבה דורשת את מקור הדף ואסימון זמני,
וקובצי הפרויקט משוחזרים אם יצירת התוספת נכשלת. אין צורך ב־Firebase
או בחיבור חשבון כדי להשתמש במנהל.
